# Crew rest calculator, offline web app

Files (keep them all in the same folder, no subfolders):
index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, apple-touch-icon.png

## Put it online (free, from an iPhone)
1. In Safari, sign in or create a free account at github.com.
2. Create a new repository (public), any name, e.g. rest-calc.
3. Choose "uploading an existing file", select ALL six files from the Files app, then Commit.
4. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
   (If Settings looks cut down, tap aA in Safari and choose Request Desktop Website.)
5. After a minute or two the app is at https://YOURNAME.github.io/rest-calc/

## Install on the iPhone
1. Open that address in Safari and wait for the calculator to appear (needs signal once).
2. Share > Add to Home Screen > Add.
3. Open it from the new icon once with signal. From then on it also opens with no signal.

## Updating later
Upload the new index.html, and in sw.js change "crew-rest-v1" to "crew-rest-v2" (then v3...).
Open the app once with signal and it updates itself.

The page is public to anyone with the address but contains no personal data.
Planning aid only: check results against your operator's approved rest rules.
